# Template — Project Management

## Tujuan

Template untuk charter proyek, status report, dan artefak manajemen proyek di vault.

## Ruang lingkup

- Format standar; isi proyek aktif berada di [[02-Projects]].

## Aturan penggunaan

- Salin template ke folder proyek; jangan edit master template untuk satu proyek saja.
- Registrasi proyek baru mengikuti [[Project-Registration-Standard]].
