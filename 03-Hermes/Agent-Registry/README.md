# Agent Registry

## Tujuan

Mencatat agent yang terdaftar di lingkungan AI Office: identitas, peran, status operasional, dan referensi ke instruksi serta skill terkait.

## Ruang lingkup

- Daftar agent (human-defined dan autonomous) yang diakui organisasi.
- Metadata registrasi; bukan runtime configuration (itu berada di Hermes Profiles).

## Aturan penggunaan

- Setiap entri agent baru memerlukan otorisasi Owner sebelum dianggap resmi.
- Gunakan wikilink ke [[03-Hermes/Agent-Instructions]] dan dokumentasi governance ([[Agent-Access-Policy]]).
- Jangan menyimpan kredensial atau secret di folder ini.
- Status dokumen mengikuti [[Document-Lifecycle]].
