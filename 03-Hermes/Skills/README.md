# Hermes Skills (Vault Index)

## Tujuan

Indeks dan dokumentasi pelengkap untuk skill yang dijalankan di Hermes — bukan salinan file SKILL.md di repository skill.

## Ruang lingkup

- Ringkasan skill AI Office, dependensi, dan kapan digunakan.
- Implementasi skill tetap di `/opt/data/skills/` (single source of truth teknis).

## Aturan penggunaan

- Perubahan prosedur eksekusi dilakukan pada skill resmi Hermes, bukan hanya di vault.
- Vault mencatat keputusan dan SOP yang disetujui Owner.
