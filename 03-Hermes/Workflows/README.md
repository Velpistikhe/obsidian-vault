# Workflows

## Tujuan

Mendokumentasikan alur kerja berulang (SOP) untuk manusia dan agent di AI Office.

## Ruang lingkup

- Prosedur operasional yang disetujui (mis. knowledge-sync, registrasi proyek, release).
- Hermes Skills tetap sumber eksekusi terautomasi; catatan di sini menjelaskan konteks bisnis dan tanggung jawab.

## Aturan penggunaan

- Satu workflow per file bernama deskriptif.
- Tautkan ke template di [[05-Templates]] bila relevan.
- Workflow yang mengubah governance harus merujuk [[Approval-Policy]].
