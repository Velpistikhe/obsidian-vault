# Execution Logs

## Tujuan

Ringkasan hasil eksekusi tugas penting (bukan log mentah sistem).

## Ruang lingkup

- Laporan singkat: tugas, tanggal, hasil, commit hash, follow-up.
- Log runtime penuh tetap di sistem Hermes; jangan menyalin log mentah berisi data sensitif.

## Aturan penggunaan

- Redaksi informasi sensitif sebelum publish.
- Ikuti [[Knowledge-Management-Policy]] untuk retensi (detail retensi: **TBD** — memerlui persetujuan Owner).
