# Agent Instructions

## Tujuan

Menyimpan instruksi operasional dan konteks kerja untuk agent yang terdaftar, terpisah dari kode dan dari konfigurasi runtime Hermes.

## Ruang lingkup

- Panduan perilaku, batasan, dan preferensi tugas per agent.
- Bukan pengganti SOUL.md, config.yaml, atau skill Hermes (sumber otoritatif tetap di workspace Hermes).

## Aturan penggunaan

- Perubahan instruksi strategis memerlukan review sesuai [[Approval-Policy]].
- Hindari duplikasi isi yang sudah ada di Hermes Skills; gunakan referensi.
- Bahasa mengikuti dokumen sumber yang direferensikan.
